CS2 WORKBENCH
版本: v1.0.5
程序名: CS2 Workbench v1.0.5.exe
构建: 2026-11-25（CS2 1.42.0.1 / build 26879581）

本版只修一个 bug，但它是「设置页的版本更新 / 回退」能不能用的关键：

1) 设置页永远停在「正在查询仓库…」，历史版本列表一片空白
   原因：renderSettings() 里读 META.frozen，但 settings 页在 bind 阶段
         （META 还没拉回来）就会先渲染一次，此刻 META 是 null，
         抛 TypeError: Cannot read properties of null (reading 'frozen')。
         checkUpdate() 的 await 之后没有 finally，异常一抛 loading 永远是 true，
         页面就卡在「正在查询仓库…」，版本列表也渲染不出来。
         接口本身正常（POST /api/update/check → 200，约 1 秒返回）。
   修复：① 「关于」区块改用 META || {} 容错，缺字段走默认值；
         ② checkUpdate() 整体包 try/finally，无论渲染是否抛错都复位 loading 并重绘；
         ③ 加并发保护，重复点「检查更新」不会叠加请求。

2) 顺带
   - 版本号全链路升到 1.0.5（server.py / index.html / app.js / theme.css / README）
   - v1.0.4 的 Release 附件里带的还是有 bug 的版本，请用 1.0.5

    当前版本标 CURRENT，其余标「可回退」，每行都有「下载 / 发布页」
